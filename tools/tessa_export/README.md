# tessa-export — экспорт голден-корпуса из СЭД Тесса

Инструмент для заказчика: запускается в рабочем контуре в Docker, раскрывает seed-список
карточек вглубь по связям и собирает архив `files/ + cards/ + cards_raw/ + manifest.json +
links_graph.json + validation_report.md` (раздел 8 ТЗ).

Инструкция по запуску (docker load, docker run, где взять результат, что делать при ошибке)
заполняется на задаче 2.8.
